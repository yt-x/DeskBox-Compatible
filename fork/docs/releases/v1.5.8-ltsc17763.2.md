# v1.5.8-ltsc17763.2

并入上游 27 个提交后的第二个可用版本。地板保持 17763，右键菜单随上游升级为 Win11 原生形态。

- 版本标识：`v1.5.8-ltsc17763.2`
- 上游基线：`bbb9e697`（PR #550 `feature/context-menu-v3`）
- 上一版本：`v1.5.8-ltsc17763.1`（上游基线 `fb6e1c4`）
- 分支：`ltsc-17763`
- 日期：2026-10-16
- 许可证：GPL-3.0-only（沿用上游；修改处在文件内标注）

## 本版变化

相对 .1，并入上游 27 个提交，主体是文件右键菜单重构：

- 右键菜单换装为 Win11 原生 CommandBarFlyout 形态（图标条 + 文字行）。
- 打开方式子菜单：平台化子菜单、应用图标预热、可执行类型隐藏入口、改走文档化 `SHOpenWithDialog`。
- 原生 ZIP 压缩/解压子菜单。
- 拖放回调隔离批：回调帧禁同步重操作，采用官方异步拖放协议。
- 菜单定位与宽度估算的多轮修复。

地板与守卫改动不受影响，全部保持。

## 构建环境补充

`Directory.Build.targets` 提供环境变量门控的 ilc 并行度约束。构建机内存紧张时设 `DESKBOX_ILC_PARALLELISM=4` 可避免 ILC 内存不足；未设置时该文件不生效，普通构建行为不变。
