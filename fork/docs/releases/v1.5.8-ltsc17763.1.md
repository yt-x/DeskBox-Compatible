## 重新构建

构建链在无管理员权限下可完整复现。

1. 安装工具链（均为用户级）：
   - .NET SDK 10.0.402：`dotnet-install.ps1 -Version 10.0.402 -InstallDir %LOCALAPPDATA%\Microsoft\dotnet`
   - Rust 1.96.0：`rustup toolchain install 1.96.0-x86_64-pc-windows-msvc --profile minimal`
   - Inno Setup 6：官方安装包以 `/PORTABLE=1 /DIR=<用户目录>` 安装
   - MSVC：VS Build Tools 含 `Microsoft.VisualStudio.Component.VC.Tools.x86.x64` 即可，无需完整 IDE
2. 编译与测试：`dotnet restore .\DeskBox.sln -p:Platform=x64`
3. 出包：`.\scripts\publish-aot-retail.ps1 -Platform x64`
4. 编译安装器：`ISCC.exe /DDeskBoxNativeAot=1 /DDeskBoxBundledRuntime=1 /DMyAppReleaseDir=..\.artifacts\aot-retail\win-x64\publish .\installer\DeskBox.iss`

发布脚本会在编译期间校验源码稳定性，因此出包过程中不要修改仓库内文件。

## 已知限制

- arm64 未出包。目标机为 x64；需要时以 `installer/DeskBox.arm64.iss` 编译。
- uxtheme 私有序数的语义正确性无独立验证手段。四个序数在 17763 上均可解析且地址互异，但解析成功不等于指向预期函数；其在目标机的实际表现由右键菜单正常运作间接确认。
- 目标机 `LongPathsEnabled` 为 0，属 Windows 10 1809 默认状态，超过 260 字符的收纳路径可能受限。此限制在上游 19041 地板上同样存在。
- 低于 17763 的 Windows 10 版本不在支持范围。
