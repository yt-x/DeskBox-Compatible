# DeskBox 17763 兼容分支

在上游 DeskBox v1.5.8 基础上把最低系统要求从 Windows 10 19041 降至 17763（LTSC 2019）的维护性私有分支：只调整版本门槛，不增改功能，不向上游贡献。许可证沿用上游 GPL-3.0-only，修改处在文件内标注声明与日期。

怎么跑：本分支暂无可运行产物；构建与运行方式与上游一致，见仓库根 README 的 Build from source 一节。
