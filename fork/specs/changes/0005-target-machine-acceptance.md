# 0005 目标机实机验收

状态：进行中

## 目标

在目标机（Windows 10 LTSC 2019 / build 17763）上验证本分支产物可用：探针报告产出、安装器完成安装、DeskBox 核心功能可用。

## 背景

前序阶段已在构建机完成全部可本地验证的工作（地板下调、契约测试、CA1416 清零、AOT 出包、载荷完整性、补丁重放）。运行期行为无法在构建机上判定：构建机为 build 26200，高于两种地板，无法区分地板是否生效，也无法暴露 17763 上的 API 缺失。

两机无网络互通，文件由用户手工搬运。

## 搬运清单

| 文件 | 来源 | 用途 |
|---|---|---|
| probes/17763-readiness.ps1 | 本仓库 | 只读探针 |
| probes/run-probe.cmd | 本仓库 | 双击运行探针并把报告写到桌面 |
| Output\DeskBox_Setup_1.5.8_x64.exe | 构建机构建产物 | 安装测试 |

安装器 SHA256：92317593B19CCE01D7EC8F220B20585DE0CD9F319FA9701A728C2C819A4C2196

## 步骤

1. 运行 `run-probe.cmd`，把桌面生成的报告文件拷回构建机。
2. 运行安装器。无需管理员权限时选择"仅为我安装"，或用命令行：
   `DeskBox_Setup_1.5.8_x64.exe /CURRENTUSER`
3. 按下列清单逐项验收。
4. 把勾选结果与任何日志拷回。

## 验收清单

- [ ] 探针在目标机运行完成，报告判定栏可读（记录 VERDICT 与全部 FAIL/WARN 项）
- [ ] 安装器启动且未出现版本不受支持的错误
- [ ] 安装完成，DeskBox.exe 可启动，托盘图标出现且进程不崩溃
- [ ] 创建一个文件格子并把测试目录放进去，格子能列出文件
- [ ] 拖入与拖出各一个文件，操作成功
- [ ] 设置窗口可打开且可修改一项设置
- [ ] 重启 DeskBox 后格子布局保持
- [ ] 全程只用测试目录，未指向真实桌面数据

## 验收判定

六项验收清单全部通过。

## 验证证据

待补（报告与验收结果存入 specs/evidence/）。

## 失败时的取证

- 探针报告：桌面 `17763-readiness-report.txt`
- 应用日志与数据：`%LocalAppData%\DeskBox\data`
- 恢复快照：`%LocalAppData%\DeskBox-Recovery`
- 若安装器拒绝运行：记录弹窗原文与 `%TEMP%` 下 Setup 日志（安装器支持 `/LOG` 参数）

## 计划外风险登记

探针只能判定 API 与依赖的存在性，无法判定 uxtheme 私有序数（104/133/135/136）是否指向预期函数——该结论只能由实际运行观察菜单主题是否正常得出。若菜单主题异常但不崩溃，属可接受的降级；若崩溃，需在 thumbnail-proxy 侧加版本守卫。
